# Week 3 – Password Cracking Lab

## Internship
Cybersecurity & Ethical Hacking – Week 3 Project

## Objective
To understand password hashes and learn how password recovery tools work using the provided password-protected PDF in an authorized lab environment.

## W3-PM1: Password Cracking with JTR
- Tools: John the Ripper (JTR) and Johnny GUI
- Platform: Windows
- Task: Extract the PDF hash and recover the password.
- Status: Completed

## W3-PM2: Password Cracking with Networkwalks Tools
- Tools: Networkwalks Hash Calculator and Password Cracker
- Platform: Web browser
- Task: Extract the PDF hash and recover the password.
- Status: Completed

## Learning Outcomes
- Learned the basics of password hashing.
- Practiced extracting hashes from a protected PDF.
- Used password recovery tools in a controlled lab.
- Understood the importance of strong passwords.
